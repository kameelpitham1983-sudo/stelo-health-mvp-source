PURPOSE
This document transcribes the question definitions embedded in the supplied HTML file.
Use it to reconstruct the questionnaire faithfully in STelo Health. Do not replace, paraphrase, invent, or clinically reinterpret source questions.
The original HTML remains the source of truth if any transcription differs.

IMPLEMENTATION INSTRUCTIONS
- Preserve all section names and order.
- Preserve every question ID, question text, input type, option, conditional follow-up prompt, and clinician note exactly.
- Preserve section-level notices as notices, not as answerable questions.
- A dependency such as dep=C7 means show the dependent field only when C7 is answered Yes, as defined in the source.
- Multi-select fields must support selecting multiple options and any source-defined Other follow-up.
- Clinician notes are for authorised clinical/admin review only; never display them to employers.
- Preserve the five fitness outcomes exactly: Fit; Fit with restrictions; Temporarily unfit; Permanently unfit; Requires specialist review.
- Keep pregnancy/reproductive health answers confidential clinical data. Employers must receive only the permitted functional fitness outcome, not these answers.
- The embedded destination CDC alert selector is a separate operational feature, not a questionnaire question. Verify current official alerts before operational reliance.
